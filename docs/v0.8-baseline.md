## 0. 一句话定位

一个 **Windows 桌面剪贴板记录工具**：后台进程常驻监听系统剪贴板并把文本落 SQLite，
前台自绘 UI 提供总览、搜索、手动录入、备注与机器信息查看；前后台通过命名管道通信，
关闭主窗口不影响记录。UI 全部由自研跨平台内核 `airui` 绘制，Win32/GDI 是默认像素后端，
Skia 是可运行时插拔的替代后端。

README 首句仍写「Windows 桌面性能录制与分析工具」，是更早的定位，与当前实际功能不符，
以本文档为准。

## 1. 运行形态：三个产物、两个常驻进程

| 产物 | CMake target | 进程/加载方式 | 职责 |
|---|---|---|---|
| `airecord.exe` | `airecord`（`CMakeLists.txt:250`） | 前台用户会话，`/SUBSYSTEM:WINDOWS` | 自绘 UI、页面、IPC 客户端、快捷操作；**不持有数据** |
| `airecordd.exe` | `airecordd`（`CMakeLists.txt:234`） | 默认「会话代理」，`-service` 为 SCM 服务 | 剪贴板监听、SQLite 读写、命名管道服务端、托盘、全局热键、会话守护 |
| `airui-skia.dll` | `airui-skia-plugin`（`:191`，`AIRUI_WITH_SKIA=ON` 才有） | 运行时 `LoadLibraryW`，按需加载 | 可选 Skia 绘制后端；缺失/ABI 不符自动回退 GDI |

进程拓扑（箭头为通信方向）：

```
  [用户会话]  airecord.exe ──命名管道(请求/响应)──> airecordd.exe (会话代理)
       │                                                │
       │  WM_COPYDATA(Toast)  <──────────────────────────┤  安装器/UAC 结果
       │  WM_APP+2(新记录通知) <─────────────────────────┤  剪贴板变化
       │                                                │
       └── airui-skia.dll (可选, 同目录)                 ├── %APPDATA%\AireRecord\airecord.db
                                                        ├── 托盘图标 + Ctrl+Shift+V 热键
                                                        └── [SCM 服务 -service] 守护各会话代理
```

**关键设计**：数据、监听、落库全在后台进程，前台 exe 崩溃/关闭不影响记录。
`airecordd.exe` 有四种模式（`src/service/main.cpp::wWinMain`）：
`-service`（SCM 服务）、`-install` / `-uninstall`（提权安装卸载）、默认（会话代理）。

**启动链路**（`src/main.cpp`、`src/core/App.cpp`）：
单实例互斥 `Local\AireRecordUiMutex` → 解析命令行 → 注册静态插件 →
`App::Run()` 建 Shell（窗口类名 `ipc::kUiWindowClass`）→ 注册 3 个页面与导航 →
`SwitchPage(0)` 触发首屏 `RefreshData()` → 消息循环。
IPC 连不上时 `PipeClient::LaunchService()` 自动拉起同目录 `airecordd.exe`
（`src/ipc/PipeClient.cpp:32-53`），不需要手工启动服务。

**SCM 服务**：`WatchThread()` 每 4s 巡检各登录会话代理，崩溃立即重启；
用户从托盘主动「退出」则写入一次性标记，该会话不再被守护
（`src/service/main.cpp:631-668`）。安装/卸载结果经 `WM_COPYDATA` 交给主界面自绘 Toast，
**服务进程绝不弹系统对话框**（Session 0 无交互桌面）。

**命令行参数**：
`--hidden`（静默启动）、`--show-after=<ms>` / `--no-activate`（延迟/不抢前台显示，
规避终端管控对「新可见窗口」的查杀）、`--paint-backend=<gdi|skia|auto>`、
`--core-shell`（启用 ShellCore/HAL 外壳，Skia 画外壳必须带此项）。

## 2. 完整功能清单（用户可见）

### 2.1 剪贴板记录（核心业务）
- **自动采集**：`AddClipboardFormatListener` + `WM_CLIPBOARDUPDATE`，只收 `CF_UNICODETEXT`；
  打开剪贴板失败重试 5 次后静默跳过（`src/service/main.cpp:145-170`）。
- **去重与置顶**：同内容再次出现时删旧插新（`Database::SaveEntry`）。
- **回写过滤**：应用内「复制」由服务端写剪贴板，记 `g_lastInternalCopy`，
  下次监听命中即丢弃，避免自己复制自己产生重复记录。
- **持久化**：SQLite，表 `entries(id, content, source, created_at, note)` + `settings` KV；
  旧库自动补 `note` 列；路径 `%APPDATA%\AireRecord\airecord.db`（用户级）。
- **来源标记**：`Clipboard` / `Manual`，总览与列表用不同图标区分。

### 2.2 三个页面

| 页面 | 文件 | 功能 |
|---|---|---|
| **工作台总览** | `src/pages/OverviewPage.cpp` | 总记录数 / 今日新增 / 库大小统计条；三张模块卡（剪贴板监控「运行中」、文件监控与打印监控「规划中·未启用」，首卡可点进剪贴板页并有 hover）；「最近动态」按时间列出条目，含空态引导 |
| **剪贴板** | `src/pages/ClipsPage.cpp` | 搜索框（内容与备注，250ms 防抖，`SearchPlugin`）；owner-draw 列表（分组日期头、来源图标、内容摘要、标签）；选中后的详情面板；行内三键「复制 / 备注 / 删除」；右键自绘菜单（复制内容 / 添加或编辑备注 / 分隔线 / 删除记录）；双击行复制；「＋ 手动录入」表单卡（内容 + 备注 + 保存）；备注可反复编辑、切换条目自动保存；空态三步引导 |
| **机器配置** | `src/pages/ConfigPage.cpp` | 双栏瀑布信息卡：服务与进程（运行模式、SCM 状态、IPC 管道名、DB 路径）、操作系统（版本/架构/计算机名/用户/开机时长）、处理器与内存（CPU 型号/核数/占用、内存总量/占用，2s 轮询）、显示与图形（显卡/主显示器分辨率/显示器数量）、磁盘（各盘剩余/总量）、网络（IP/网卡/连接态）、快捷键清单、功能模块注册表（1/3 已启用） |

侧栏硬编码三组（`App.cpp:213-243`）：功能模块（总览 / 剪贴板 / 文件监控·规划中 / 打印监控·规划中）、
快捷操作（手动录入 F4 / 清空剪贴板记录）、系统（机器配置 / 服务管理）。
标题栏有「服务运行中 · 已记录 N 条」胶囊和「渲染: GDI / Skia」切换按钮；
状态栏显示服务连通性、启用模块数与 F3/F4/Ctrl+Shift+V 提示；侧栏有角标与本机信息卡。

### 2.3 快捷方式与反馈
- **Ctrl+Shift+V**：全局热键（服务侧 `RegisterHotKey`），呼出/隐藏主界面；托盘双击同效。
- **F3**：切到剪贴板页、聚焦搜索框并全选；**F4**：切到剪贴板页、展开手动录入卡并聚焦录入框。
  两者在**消息循环**里过滤（`App.cpp:180-198`），而不是窗口过程 —— 焦点常在子控件上，
  主窗口收不到按键消息；模态对话框打开或窗口隐藏时不抢键。
- **自绘 Toast**（`OverlayWindow.cpp`）：淡入/淡出、3.2s 寿命、最多 3 条堆叠、× 关闭、
  成功/警告/错误/信息四色、按显示器工作区 clamp、owner 隐藏/最小化时**冻结显示时钟**。
  覆盖复制、删除、备注、清空、手动录入保存、后端切换、服务安装结果、UAC 被拒等所有结果。
- **自绘确认框**（`RunModalDialog`）：WS_EX_LAYERED 浮层 + 遮罩覆盖整个窗口矩形（含标题栏）、
  Enter/Esc/Tab、按钮 hover/pressed、owner 禁用态保存恢复；用于清空记录、删除条目。
- **自绘右键菜单**（`RunPopupMenu`）：复用 core `PaintMenu / MenuItemAt / MenuContentHeight`，
  hover 高亮、方向键、Enter/Esc、点击外部取消、锚点翻转与工作区 clamp。
  主界面内 **0 个 `MessageBoxW` / `TrackPopupMenu`**；仅会话代理的系统托盘菜单保留原生
  （通知区 UI，且该进程不链接 airui）。
- **IPC 失败不再假成功**：所有 `Ipc().Request()` 校验 `OK` 前缀，失败给错误 Toast。

### 2.4 渲染后端（运行时可插拔，非编译开关）
`PainterRegistry` 按 id 注册三种 provider（`src/airui/platform/win32/PaintProviders.cpp`）：
`gdi`（默认，始终可用）、静态链接 `skia`（`AIRUI_WITH_SKIA=ON`）、DLL 插件 `skia`
（`SkiaPluginAbi.h` 稳定纯 C ABI + `LoadLibraryW` + ABI 版本严格相等 + 按需加载）。
四种选择入口：`--paint-backend`、`AIRUI_PAINT_BACKEND`、标题栏按钮、`Shell::SetPaintBackend()`
热切换；不可用自动回退 gdi。`client.log` 的 `[paint]` 行记录
`requested/resolved/available/skiaDll/probe/text`，可判定是否真在用 Skia。
`AIRUI_WITH_SKIA` 默认 **OFF**，只决定本次**是否构建** Skia 代码。

> 只有带 `--core-shell` 时 `PainterRegistry` 才接管整窗绘制；默认富渲染路径由 GDI 直画。
> 插件与 exe **位数必须一致**（本机 `build/` 是 VS2017 Win32，CI 插件是 x64）。

## 3. 架构分层

```
src/
├── airui/core/            23.5k 行  ★平台无关 UI 内核（静态库 airui-core）
│   ├── include/airui/     FrameworkCore / ShellCore / Theme / Layout / UiText / hal.h /
│   │                      ControlsCore,Advanced,Enterprise,Studio,Extra / Interaction /
│   │                      PaintBackend / PaintRecorder / OverlayCore / Observable / Animation
│   └── src/               自由函数内核 + ControlsClasses.cpp 类体系转发 shim
├── airui/platform/win32/  9.6k 行  Win32/GDI 后端：Shell / Page / Widgets / Controls /
│                                  Canvas / GdiPainter / Fonts / Gfx / PaintFrame /
│                                  PaintProviders / OverlayWindow / ThemeManager / Accessibility
├── airui/platform/skia/   2.1k 行  SkiaPainter / SkiaSurface / SkiaPluginAbi.h（opt-in）
├── core/                  1.6k 行  App（门面）· Database(SQLite) · MachineConfig(ini) ·
│                                  SysInfo · Format · PluginManager · UiEntry · DiagLog
├── pages/                 1.8k 行  OverviewPage / ClipsPage / ConfigPage（IPage 实现）
├── plugins/                138 行  SearchPlugin / ManualEntryPlugin（IFeaturePlugin，静态编译）
├── ipc/                    355 行  Ipc(协议/转义) · PipeClient · PipeServer
├── service/                868 行  会话代理 + SCM 服务（单一 main.cpp）
├── gallery/               4.1k 行  组件画廊（Command + Demos() 注册表）
└── main.cpp                        客户端入口
tests/  38 个文件 / 7.8k 行   ·   docs/ 7 篇   ·   scripts/ 13 个取证与门禁脚本
```

依赖方向：`pages / plugins → core(App) → ipc`，`core / pages → airui-core → airui-win32 → Win32`。
`App` 只做门面（持有 Shell、IPC、插件、共享数据），**不含任何绘制**；界面能力全部来自 airui。

### 3.1 五条设计契约（v0.9 之前必须保持）
1. **core owns state & layout, backend owns pixels**（`ShellCore.h`）：平台无关层算几何、
   命中与状态，Win32 层只出像素。`ShellOptions.coreShell` 是可选的 HAL 外壳路径（默认关）。
2. **Command + Registry**：近百个控件类（`: public Control` 声明 99 处）继承
   `FrameworkCore.h::Control`，`ControlsClasses.cpp` 把方法转发回自由函数内核；
   画廊用 `Demos()` 单一注册表。新增控件写法见 `docs/design-patterns.md`。
3. **绘制金样**：core `PaintRecorder` 把 `IPainter` 调用录成 `PaintOp`，
   `Matches / SequenceEquals / Diff / ToString` 支持三平台确定性比对；
   `test_paint_recorder` / `test_skia_backend` 固化跨后端一致性。
4. **字体唯一来源**：`src/airui/core/include/airui/UiText.h`（`kFamilyUi`、
   `kCell`、`kWeight`）；GDI 走 `Fonts`/`Metrics`，Skia 用 `MeasureRole()` 在目标字号直测
   GDI 宽度迭代收敛；ClearType 与 Skia 亚像素 AA 必须同路。
5. **交互状态机**：core `Interaction.h::HotState`（悬停/按下/抬起），按下只改视觉、
   动作落在抬起；命中矩形与事件坐标必须同一坐标系；分块失效避免整窗重绘闪烁。

### 3.2 数据与通信协议
- **命名管道**（`src/ipc/Ipc.h`）：UTF-8、`\t` 分字段、`\n` 分记录，
  内容字段经 `EscapeField` 转义，保证原始 `\n` 只作分隔符；管道名从
  `%PROGRAMDATA%\AireRecord\service.ini` 的 `[service] pipe_name` 读取并追加
  `_s<会话ID>` 做会话隔离。
- **命令集**（`src/service/main.cpp::HandleIpc`）：
  `PING` / `LIST\t<filter>`（最多 500 条）/ `SAVE`（手动录入）/ `NOTE`（改备注）/
  `DEL` / `CLEAR` / `COPY`（服务端写剪贴板）/ `STATS`（总数、今日、库字节）/
  `UI`（唤起主界面）；响应 `OK` 或 `ERR\t<原因>`。
- **反向通知**：新记录 → `NotifyClientRefresh()` → `WM_APP+2` → 300ms 防抖 →
  `App::RefreshData()`（**唯一收口**：全量快照 + STATS + 外壳文案 + invalidate）。
  这条链路与「当前停在哪一页」无关，是 v0.8 修掉「总览页复制不刷新」的成果。
- **配置分层**（`MachineConfig.h`）：用户级 `%APPDATA%`（DB + 偏好），
  机器级 `%PROGRAMDATA%\AireRecord\service.ini`（`pipe_name` / `log_level` /
  `run_mode` / `defer_show_ms` / `client_path` / `provision_client_to`）。
- **跨进程 Toast**：提升进程 / 服务用 `WM_COPYDATA`（`ipc::kUiWindowClass` +
  `kUiToastTag 0x41525431`），载荷 `ok\t标题\t正文`，主窗口 message hook 解析后自绘。
- **静态插件**：`PluginManager` 注册顺序分发、逆序卸载，接口 `IFeaturePlugin`
  直接吃 `App&` / `HWND` / 控件 id（`src/core/Plugin.h`）。**这是编译进 exe 的模块，
  不是可插拔 DLL** —— 真正可插拔的范本是 `airui-skia.dll`。

## 6. 复现这个基线

```bash
git checkout v0.8
# Windows（官方）
build.bat
cmake --build build --config Release      # 本机已配好的 VS2017 Win32 缓存
cd build && ctest -C Release --output-on-failure
bash scripts/check-core-clean.sh

# 运行
build/Release/airecordd.exe               # 会话代理（也可 -install 装成系统服务）
build/Release/airecord.exe --paint-backend=gdi --core-shell
```

对照检查：`git diff v0.8..main --stat` 应能看出后续版本相对本基线改动了哪些层。
